# 名笺 MingJian · AI 起名

> 一个纯前端的中文起名工具：用音律、字义、五行、五格与独特性五个维度，把「好听」拆成可以解释的分数。

**零依赖、零后端、开箱即用。** 打开 `index.html` 就能起名；也可以选填一个大模型 API Key，让模型先出创意，再由本地引擎复核音律与笔画。

---

## 功能

- **五种起名模式**：男孩 / 女孩 / 中性，双字名与单字名
- **八个风格标签**：诗意、清雅、大气、古风、温润、明亮、现代、中性（可多选）
- **五行喜用**：金木水火土任选，按字面五行筛选并计分
- **寓意关键词**：填「光明 坚韧 山水」，命中的字会加寓意分
- **避讳字**：家里长辈用过的字，一键排除
- **逐字解析**：拼音、声调、五行、笔画、字义、五格数理，每个名字都能讲清为什么
- **一批不重字**：同一批结果尽量不共用字，不会出现「李聿绾、李珩聿」这种扎堆
- **收藏与导出**：收藏夹存在本地，候选可一键导出 CSV
- **可选大模型**：兼容任意 OpenAI Chat Completions 接口（DeepSeek、通义、豆包方舟等），Key 只存在浏览器 localStorage

## 快速开始

### 方式一：直接打开

下载仓库后双击 `index.html`，全程离线可用，不需要 Node，也不需要联网。

### 方式二：起一个本地静态服务（推荐）

```bash
git clone https://github.com/sgwhs/ai-namer.git
cd ai-namer
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 用本地服务而不是 `file://` 打开，是为了让「可选的大模型接口」能够正常发起跨域请求。

### 方式三：部署到 GitHub Pages

Pages 首次使用需要仓库管理员手动开启（`GITHUB_TOKEN` 无仓库管理权限，无法由工作流代为开启）：

1. 仓库 **Settings → Pages → Build and deployment**，Source 选 **GitHub Actions**
2. 到 **Actions → Deploy to GitHub Pages → Run workflow** 手动跑一次（工作流已设为仅手动触发，避免未开启时刷出一片失败任务）
3. 站点地址为 `https://sgwhs.github.io/ai-namer/`

> 开启之后，如果想恢复“每次 push 自动发布”，把 `.github/workflows/deploy-pages.yml` 里的 `on:` 加回 `push: branches: [main]` 即可。

## 接入大模型（可选）

点右上角「大模型」，填写三项即可：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| 接口地址 | `https://api.deepseek.com/v1` | OpenAI 兼容的 Base URL，不带 `/chat/completions` |
| API Key | `sk-...` | 仅保存在本机 `localStorage`，不会写入代码或上传 |
| 模型名 | `deepseek-chat` | 留空默认 `gpt-4o-mini` |

调用流程是「**模型出创意 → 本地引擎复核**」：

1. 模型按姓氏、性别、字数、风格、五行、寓意关键词返回 JSON 候选（含拼音、字义、五行、笔画）
2. 本地引擎对每个候选重新计算音律、寓意、五行、五格、独特性，重新打分排序
3. 模型不可用、超时或返回格式异常时，自动回退到内置词库，不会出现空白页

**关于跨域（CORS）**：浏览器直连第三方接口时，若对方未放行跨域请求，会提示「连不上接口」。解决办法有两种：

- 用本地静态服务打开页面（`http://localhost` 通常比 `file://` 更宽松）
- 换用支持浏览器跨域调用的接口地址，或自建一个转发代理

> 也可以把 Key 放在后端代理里，前端不接触密钥——这是更稳妥的生产做法，本项目作为纯前端工具不强制。

## 评分算法

综合分 = 音律 35% + 寓意 27% + 五行 13% + 五格笔画 15% + 独特性 10%

| 维度 | 权重 | 看什么 |
| --- | --- | --- |
| 音律 | 35% | 声调是否错落、声母韵母是否重复、与姓氏连读是否拗口、是否连续上声 |
| 寓意 | 27% | 字义是否命中用户的寓意关键词与风格标签，两字气质是否一致 |
| 五行 | 13% | 字面五行是否命中喜用；未指定时看两字五行是否有变化 |
| 五格笔画 | 15% | 天格 / 人格 / 地格 / 总格，按 81 数理吉凶简化表计分 |
| 独特性 | 10% | 用字热度：两字都冷僻会扣分（可读性差），常见而不俗会加分 |

等级：`上上` ≥ 92 / `上` ≥ 86 / `中上` ≥ 80 / `中` ≥ 74 / 其余为 `参考`。

生成时还会做这些硬性过滤：

- 名字不含姓氏用字，不与姓氏同音
- 两字不相同、拼音不完全相同
- 一男一女倾向的字不混搭
- 避讳字、用户排除的字不出现

更细的规则见 [`docs/算法说明.md`](docs/算法说明.md)。

## 数据说明

- 字库收录 130+ 个常用雅字，覆盖男女中性三类气质，字段包含拼音、声调、五行、笔画、热度与字义
- 笔画为简体常用笔画近似值，用于五格参考，不作为字典定论
- 五行按字义与偏旁的传统归类，不同流派可能有差异
- 姓氏覆盖 100 个常见单姓与 15 个复姓；未收录的姓氏仍能起名，但音律衔接与五格会降级处理

## 免责声明

本项目的评分是一套**可解释的启发式规则**，用于辅助筛选与比较，不构成命理、八字或任何形式的专业命名结论。名字最终由你和家人决定。
