# 算法说明

这份文档解释「名笺」为什么给某个名字打这个分。所有规则都写在 `assets/js/engine.js` 里，可以逐条对照。

## 1. 生成流程

```
姓氏解析 → 候选字池筛选 → 两两组合 → 五维打分 → 过滤 → 排序 → 一批内去重 → 输出
```

### 1.1 姓氏解析

- 先查复姓表（欧阳、司马、上官、诸葛等 15 个），再查单姓表（100 个常见姓）
- 每个姓带拼音与笔画，用于音律衔接和五格计算
- 未收录的姓氏不报错：照常生成，只是音律中的「姓音衔接」与五格的「天格/人格」按降级处理

### 1.2 候选字池

基础过滤：

- 排除避讳字
- 排除姓氏中出现的字（避免「林林」）
- 按性别倾向过滤：`m` 只出男字与中性字，`f` 只出女字与中性字，`n` 全出
- 指定五行时，只保留该五行的字
- 指定风格时，只保留标签命中的字

如果风格筛完不足 24 个字，会逐步放宽（先允许 `neutral` 与 `modern` 互通，再退回只按性别/五行过滤），保证不会因为条件太窄而无名可起。

### 1.3 组合与硬性过滤

双字名做有序两两组合，以下情况直接丢弃：

- 两字相同
- 两字拼音（去声调）完全相同
- 一男一女两个字混搭（如「铠」+「婉」）
- 单字名则逐字评估

## 2. 五个维度

### 2.1 音律（权重 35%）

基础分 62，按以下规则加减：

| 规则 | 调整 |
| --- | --- |
| 名内两字声调不同 | +14 |
| 名内两字声调相同 | −6，并记录提示 |
| 连续两个上声（三声） | 再 −6 |
| 名内两字韵母相同 | −20 |
| 名内两字声母相同 | −14 |
| 名首字声调与姓氏不同 | +10 |
| 名首字声调与姓氏相同 | −3 |
| 名首字与姓氏押韵 | −12 |
| 名首字与姓氏声母相同 | −8 |
| 名末字与姓氏押韵 | −6 |

上限 100、下限 30。拼音处理时把 `y` 还原为 `i`、`w` 还原为 `u`、`yu` 还原为 `ü`（内部记作 `v`），再取韵母，保证 `yuan` 与 `yan` 不会被误判为同韵。

### 2.2 寓意（权重 27%）

基础分 55：

- 每个字义命中一个用户关键词：+16（可叠加）
- 每个字命中用户风格标签：每个标签 +6，单字最多 +12
- 两字共享 2 个以上标签：+6（气质一致）
- 用户既没填关键词也没选风格：固定 76 分（中性可延展）

### 2.3 五行（权重 13%）

- 指定喜用五行：`45 + 命中字数 / 总字数 × 55`
- 未指定：两字五行不同给 86（有变化），相同给 80

### 2.4 五格笔画（权重 15%）

按传统五格剖象：

```
天格 = 单姓：姓笔画 + 1；复姓：姓总笔画
人格 = 姓笔画 + 名首字笔画
地格 = 双字名：两字笔画和；单字名：名笔画 + 1
总格 = 姓笔画 + 名笔画和
```

每个格按 81 数理归一到 1–81，查简化吉凶表：

- 吉数 → 95
- 半吉数 → 80
- 其余 → 62

加权（人格 40% + 地格 35% + 总格 25%）得到笔画分。姓氏笔画未知时统一给 78，并在详情里标注。

> 81 数理表为简化版，只用于横向比较，不作为命理结论。

### 2.5 独特性（权重 10%）

字库里每个字有 1–5 的热度值（1 最冷门，5 最热门）：

```
基础分 = 100 − (平均热度 − 1) × 13
两个都是冷僻字（热度 ≤ 2）：−22
一个冷僻、且没有热门字：−6
至少一个热门字且没有冷僻字：+4
单字名且冷僻：−10
```

这样既不会一味推冷僻字（可读性差），也不会全是「梓涵」式的爆款字。冷僻组合会附带提示，由用户自己权衡。

## 3. 综合分与等级

```
综合分 = 音律×0.35 + 寓意×0.27 + 五行×0.13 + 笔画×0.15 + 独特×0.10
```

生成时会加一个 `0–3.5` 的随机扰动，让「换一批」有新结果，但不会把明显更差的组合顶上来。上限 99。

| 等级 | 分数 |
| --- | --- |
| 上上 | ≥ 92 |
| 上 | ≥ 86 |
| 中上 | ≥ 80 |
| 中 | ≥ 74 |
| 参考 | < 74 |

## 4. 一批内去重

排序后按顺序取名字，优先选**与已选结果不共用任何字**的候选；凑不满目标数量时再放宽补足。这样一批 12 个名字通常会用掉 24 个不同的字，不会出现同字扎堆。

## 5. 大模型结果的复核

大模型返回的名字不会直接展示，而是走一遍本地引擎：

1. 逐字查字库；字库里有就直接用库里的拼音、五行、笔画、热度与字义
2. 字库没有的字，采用模型返回的拼音、五行、笔画，热度按 2 处理（偏冷门）
3. 用同一套 `evaluate()` 重新计算五维分与五格
4. 字数不符、含姓氏、非汉字的候选直接丢弃

因此同一个名字，无论来自词库还是模型，评分口径一致，可以直接比较。

## 6. 已知局限

- 字库规模有限（130+ 字），冷门姓氏与生僻用字覆盖不足
- 字义是人工撰写的一句话，无法表达两字组合后的整体意境（如「知远」的化学反应）
- 未接入谐音词表，暂不主动规避不雅谐音
- 五格笔画用简体近似值，与康熙笔画流派存在差异
- 评分是启发式规则，不是模型预测，不能替代专业命名服务

欢迎在 Issue 里补充字库、谐音词表或新的评分维度。
